App for tracking revision topics using spaced repetition

## FEATURES
- Select one of 5 users
- Add a topic and start date
- Automatically creates revision dates after:
  - 1 week
  - 1 month
  - 3 months
  - 6 months
  - 1 year
- Shows upcoming revisions only
- Sorts revisions by date
- Saves data in localStorage

## Running locally
Install dependencies:

npm install

## Testing

Unit tests are in agenda.test.mjs.
